## **Step 1 – Outline Requirements**

From your description and data:

1. **Penalty for Sell-Offs**

   * If **volume increases sharply but price decreases**, model should treat it as a **negative (bearish)** signal.
   * Example: `VolRatio > 1.2` **and** `Close_t < Close_{t-1}` → penalize score.

2. **Reward for Divergence with RSI**

   * If **RSI is low (<30–40) but price increases**, model should give a **bullish boost** (likely further upside).
   * Example: `RSI < 40` **and** `Close_t > Close_{t-1}` → reward.

3. **Overbought / Overheated condition**

   * If RSI is very high (>70–80) and volume is spiking → stronger penalty (signal exhaustion).
   * Example: `RSI > 75` and `VolRatio > 1.2` → bearish weight.

4. **Context sensitivity**

   * Don’t just use raw `RSI` or `VolRatio`. Instead, use **interactions**:

     * `(VolRatio * PriceChange)`
     * `(RSI * PriceChange)`
     * `(RSI * VolRatio)`
   * These interaction features capture your “if this AND that” logic.

5. **Integration with current models**

   * For **XGBoost**:
     → Add engineered features capturing the penalty/reward rules.
   * For **LSTM**:
     → Feed in the engineered features as additional channels alongside price/volume.

## **Step 2 – Implementation Suggestions**

### **A. Feature Engineering**

Add these features before training:

* **PriceChange%** = `(Close_t - Close_{t-1}) / Close_{t-1}`
* **VolChange%** = `(Volume_t - Volume_{t-1}) / Volume_{t-1}`
* **SellOffFlag** = `1 if VolChange% > 20% and PriceChange% < 0 else 0`
* **RSI\_PriceInteraction** = `RSI * PriceChange%`
* **Vol\_PriceInteraction** = `VolRatio * PriceChange%`
* **OverboughtSpike** = `1 if RSI > 75 and VolRatio > 1.2 else 0`

These give XGBoost and LSTM the "penalty/reward" signals.
